Переключи glm-router в режим ПОЛУАВТО. Советник только рекомендует модель и не переключает сессию. Новый сеанс ZCode нужен, чтобы хук увидел конфиг: снимок хуков делается при старте сессии.

Выполни только:

`node bin/glm-router.mjs mode semi`

Покажи stdout. Не читай `~/.zcode` и не отправляй задачу в платную модель.
