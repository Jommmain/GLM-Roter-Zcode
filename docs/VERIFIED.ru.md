# Что сверено с документацией

Дата чтения страниц: 6 ноября 2026 года. Страницы не помечены сборкой ZCode Desktop 3.17.2. Интеграция поля `model` с провайдером считается непроверенной, пока дымовой тест в вашем клиенте её не подтвердит.

## Опираемся на текст docs

- [Plugin](https://zcode.z.ai/en/docs/plugin): каталог `.zcode-plugin/plugin.json`, `commands/*.md`, `agents/*.md`, `hooks/hooks.json`. Стандартные хуки обнаруживаются сами; повторная регистрация того же файла даёт диагностику и пропуск дубликата. Команда: frontmatter, `$ARGUMENTS`, `$1`/`$2`, поле `model` — «Overrides the default model». Имя команды: `^[a-z0-9][a-z0-9_:-]{0,63}$`. Имя плагина: `^[a-z0-9][a-z0-9._-]{0,127}$`. Локальный marketplace добавляется через Settings → Plugins → Create → Add marketplace. В `marketplace.json` обязательны `name` и `plugins[]`; у записи обязателен `name`, обычный `source` — относительный путь.
- [Hooks](https://zcode.z.ai/en/docs/hooks): хук получает одну строку JSON на stdin и не получает объект, которым можно вызвать модель. `UserPromptSubmit` видит `prompt`, может добавить `additionalContext` или заблокировать запрос и не может переписать исходный prompt. Неизвестные поля игнорируются. `PreToolUse` может вернуть `permissionDecision` и полный `updatedInput` аргументов инструмента, не модель сессии. Пустой stdout — успех без эффекта. Код выхода 0 разбирает stdout; прочий ненулевой код роняет только текущий хук. Переменные `ZCODE_PLUGIN_ROOT` и `ZCODE_PLUGIN_DATA`. Исполнитель `process` — это `command` плюс `args` без shell. Снимок хуков берётся на старте сессии.
- [Subagents](https://zcode.z.ai/en/docs/subagents): субагент запускается инструментом Agent в отдельном контексте. Поле `model` — конкретный id, `inherit` или пропуск (тогда модель основной сессии). Неизвестные ключи фронтматтера молча игнорируются.
- [Commands](https://zcode.z.ai/en/docs/commands): встроенные команды страницы — `/goal` и `/compact`. Команды `/model` там нет.
- [Connect Models](https://zcode.z.ai/en/docs/configuration): встроенные GLM-5.3 и GLM-5.3-Flash через BigModel / Z.ai. Селектор открывается щелчком по имени модели в поле ввода. OpenRouter добавляется как свой провайдер с базовым URL `https://openrouter.ai/api`. Для Coding Plan встроенная GLM-5.3-Flash описана как мультимодальная модель скриншотов; тот же GLM через другой провайдер или протокол может не принимать изображения. Имя модели само по себе способность не доказывает.

## Намеренно не используем

- Поле `model` в командах и активных агентах: нет правила, какой провайдер выиграет при одинаковом имени.
- `userConfig`: в документации значение подставляется в MCP как `${user_config.ключ}`, не в хук.
- Чтение `~/.zcode/v2/config.json` и любых файлов приложения. Там лежат ключи.
- Живую квоту. Её нет в контракте хука.
- `updatedInput` для подмены модели. Он меняет аргументы инструмента.
- Автоматический переход на другой провайдер, если квота подписки кончилась.
